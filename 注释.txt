## IK_CONFIG 自动生成（LAFAN1 源，semi_taks_lv1 / semi_taks_lv1_chassis）
# 注意：TPOSE.bvh 已缺失，LAFAN1 motion 首帧是动作姿态（非干净 T-pose），
# 直接用首帧标定会使 quat 偏移杂乱、坐标系混乱。正确做法是两步：
#   1) generate_keypoint_mapping_bvh.py 用 run.bvh 首帧算 pos/scale（pos 偏移与人体朝向无关，可用）；
#   2) fix_lafan1_quat_from_taks1.py 从 taks_t1 的干净 LAFAN1 偏移反推 LAFAN1 T-pose 骨朝向，
#      重写 quat 偏移为干净轴对齐值（保留第 1 步的 pos/scale；chassis 的 base_link->Hips 保持强制 [1,0,0,0]）。
#      Head 朝向用 Spine2 近似（T-pose 头与脊柱同向）；chassis 的 LeftFoot 用 LeftFootMod、Spine1 用 Spine2。
#      额外整体乘 Rz(-90°) 对齐朝向：新 LV1 固定基座 pose_init 为单位朝向(+X)，而 LAFAN1 人 T-pose 朝 -Y
#      （taks_t1 靠 pose_init root_rot=-90°z 对齐），故 semi 需在 delta 偏移上再乘 Rz(-90°) 使上身朝 -Y 贴合人。

# 第 1 步（semi_taks_lv1，固定基座，无 <attach>）：
python ik_config_manager/generate_keypoint_mapping_bvh.py \
    --bvh_file data/LAFAN1/run.bvh --format lafan1 --robot semi_taks_lv1 \
    --robot_qpos_init ik_config_manager/pose_inits/semi_taks_lv1_tpose.json \
    --ik_config_in general_motion_retargeting/ik_configs/bvh_lafan1_to_semi_taks_lv1.json \
    --ik_config_out general_motion_retargeting/ik_configs/bvh_lafan1_to_semi_taks_lv1.json
# （标定阶段写完配置即 [SUCCESS]；其后可视化阶段需显示器，无显示时报错可忽略）

# 第 1 步（semi_taks_lv1_chassis，含 <attach>，用 calibrate_chassis_lv1.py 绕过 + scale 1.0）：
